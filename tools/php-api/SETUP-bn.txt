কেয়ারির মন্তব্য ও পড়ার-সংখ্যা সার্ভার — নিজের হোস্টিং-এ (cPanel), পুরোনো সাইটে হাত না দিয়ে
=====================================================================================

নিয়ম: পুরোনো সাইটের (public_html, ওয়ার্ডপ্রেস, তার ডেটাবেস) কিছুই খোলা/বদলানো/মোছা হবে না।
আমরা শুধু ৩টি নতুন জিনিস বানাব — নতুন ডেটাবেস, নতুন সাবডোমেন (নিজস্ব ফোল্ডারসহ), আর একটি গোপন কনফিগ ফাইল।
ভুল হলে এই ৩টি নতুন জিনিস মুছে আবার বানালেই হয়; পুরোনো সাইটের কোনো ক্ষতি নেই।

---------------------------------------------------------------------------------
আগে (৫ মিনিট): ব্যাকআপ — তবু নিয়ম মেনে
  cPanel → Backup → "Download a Full Account Backup" নামিয়ে পিসিতে রাখুন। (কিছু বদলাব না, তবু নিরাপদ থাকার জন্য)

ধাপ ১ — নতুন ডেটাবেস (ওয়ার্ডপ্রেসেরটা নয়)
  cPanel → "MySQL® Database Wizard":
    ১) ডেটাবেসের নাম: keyari   (cPanel নিজে আগে আপনার ইউজার-নাম বসিয়ে দেবে, যেমন abc_keyari)
    ২) নতুন ইউজার: keyari   + "Password Generator" দিয়ে লম্বা পাসওয়ার্ড — কপি করে একটা নোটে রাখুন
    ৩) অনুমতি: "ALL PRIVILEGES" (এটি শুধু এই নতুন ডেটাবেসের জন্য; ওয়ার্ডপ্রেসের ডেটাবেসের সঙ্গে সম্পর্ক নেই)

ধাপ ২ — নতুন সাবডোমেন (পুরোনো সাইট থেকে সম্পূর্ণ আলাদা ফোল্ডারে)
  cPanel → Domains → "Create A New Domain":
    Domain: api.thekeyari.com
    "Share document root" — টিক তুলে দিন (আনচেক)
    Document Root: keyari-api     ← public_html-এর ভেতরে নয়; হোম ডিরেক্টরিতে নতুন ফোল্ডার
  cPanel → SSL/TLS Status → api.thekeyari.com-এর জন্য "Run AutoSSL" (ফ্রি HTTPS)

ধাপ ৩ — ফাইল আপলোড
  File Manager → keyari-api ফোল্ডারে (public_html-এ নয়!) এই ফাইলগুলো আপলোড করুন:
    index.php   এবং   .htaccess      (Settings-এ "Show Hidden Files" চালু রাখুন)
  import-wp.php এখন আপলোড করবেন না — জানুয়ারিতে লাগবে।

ধাপ ৪ — গোপন কনফিগ ফাইল (সবচেয়ে গুরুত্বপূর্ণ)
  File Manager-এ হোম ডিরেক্টরিতে ( /home/আপনার-ইউজার/ — keyari-api ফোল্ডারের ঠিক বাইরে ) একটা ফাইল বানান:
    নাম: keyari-config.php
  এর ভেতরে এই লেখা বসান (নিজের তথ্য দিয়ে):

    <?php
    return [
        'db_host' => 'localhost',
        'db_name' => 'আপনার-ইউজার_keyari',
        'db_user' => 'আপনার-ইউজার_keyari',
        'db_pass' => 'ধাপ ১-এ রাখা পাসওয়ার্ড',
        'admin_token' => 'আরেকটা লম্বা এলোমেলো গোপন পাসওয়ার্ড (অ্যাডমিনে মন্তব্য সামলাতে)',
        'salt' => 'যেকোনো এলোমেলো লেখা',
        'allowed_origins' => 'https://gunjoron-test.github.io,https://thekeyari.com,https://www.thekeyari.com',
    ];

  কেন এখানে: হোম ডিরেক্টরির ফাইল কোনো ঠিকানা থেকেই ব্রাউজারে খোলা যায় না — ওয়েব-ফোল্ডারের বাইরে, তাই পাসওয়ার্ড ফাঁস হওয়ার পথ নেই।
  এই ফাইল কখনো গিটহাবে/ইমেইলে/চ্যাটে দেবেন না (আমাকেও না)।

ধাপ ৫ — চালু হয়েছে কি না
  ব্রাউজারে https://api.thekeyari.com/ খুলুন → দেখাবে:  {"ok":true,"service":"keyari-comments-php"}
  (টেবিলগুলো প্রথম খোলাতেই নিজে তৈরি হয়ে যায়।)
  ত্রুটি দেখালে বার্তাটা আমাকে পাঠান (পাসওয়ার্ড বাদে)।

ধাপ ৬ — সাইটকে ঠিকানা জানানো
  অ্যাডমিন → সেটিংস → মন্তব্য → "কেয়ারির নিজস্ব মন্তব্য-সার্ভার" ঠিকানা:  https://api.thekeyari.com   → সংরক্ষণ।
  অ্যাডমিনের মন্তব্য-পাতায় পাসওয়ার্ড চাইলে ধাপ ৪-এর admin_token দিন।

জানুয়ারিতে (নতুন সাইট লঞ্চের সময়):
  - এই ঠিকানা (api.thekeyari.com) একই থাকবে, কিছু বদলাতে হবে না।
  - ওয়ার্ডপ্রেসের পুরোনো মন্তব্য/ভিউ আনতে import-wp.php-র নির্দেশ তখন আলাদা করে দেওয়া হবে।

নিরাপত্তা সংক্ষেপে
  - পুরোনো সাইট, তার ফোল্ডার ও ডেটাবেস অক্ষত।
  - পাসওয়ার্ড শুধু হোম ডিরেক্টরির keyari-config.php-তে; গিটহাবে কিছু নেই (.gitignore এ আটকানো)।
  - ডেটাবেসের ইউজার শুধু নতুন ডেটাবেসের — হ্যাক হলেও ওয়ার্ডপ্রেসের ডেটা ছোঁয়া যায় না।
  - শুধু https ঠিকানা থেকে অনুরোধ নেয়; অচেনা ওয়েবসাইট থেকে মন্তব্য/ভিউ পাঠানো আটকায় (allowed_origins)।
  - মন্তব্য অনুমোদনের আগে সাইটে দেখায় না; ঘণ্টায় একই আইপি থেকে ৫টির বেশি মন্তব্য আটকায়।
