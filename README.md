# কেয়ারি — শিল্প-সাহিত্য ও চিন্তাশীলনের ওয়েবজিন

`thekeyari.com`-এর নতুন সাইট ও সম্পাদনা কক্ষ (অ্যাডমিন প্যানেল)। এটি `keyari-master-prompt.md` অনুযায়ী বানানো।

- **সাইট:** আগে থেকে তৈরি HTML পাতা (স্ট্যাটিক)। খুব দ্রুত চলে, কোনো সার্ভার বা ডেটাবেস লাগে না, আর সার্চ ইঞ্জিনে র‍্যাংক করার জন্য উপযুক্ত।
- **হোস্টিং:** GitHub Pages, বিনামূল্যে। রিপোতে কিছু পরিবর্তন হলে GitHub Actions নিজে থেকে সাইটটি নতুন করে তৈরি করে প্রকাশ করে।
- **অ্যাডমিন প্যানেল:** `/admin/` ঠিকানায় থাকে। লেখা সংরক্ষণ করলে তা সরাসরি GitHub রিপোতে জমা হয়, ১–২ মিনিটের মধ্যে সাইটে দেখা যায়।
- **কনটেন্ট:** পুরোনো WordPress সাইট থেকে ১২৮টি লেখা, ৯২ জন লেখক, সব বিভাগ, আপনকথা, বিশেষ বার্তা আর "রাজা যায় রাজা আসে" আয়োজন এখানে আনা হয়েছে। পুরোনো সাইটের সব ঠিকানা (URL) যেমন ছিল তেমনই আছে।

## ১. একবারের সেটআপ (১০ মিনিট)

### ধাপ ১ — GitHub-এ রিপো বানান
1. github.com-এ গিয়ে **New repository** চাপুন। নাম দিন, যেমন `keyari`। **Public** বাছুন (নিচের "গোপনীয়তা" অংশটি পড়ে নিন)।
2. এই ফোল্ডারের সব ফাইল রিপোতে তুলুন। কম্পিউটারে git থাকলে:
   ```bash
   git init
   git add .
   git commit -m "কেয়ারি সাইট"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/keyari.git
   git push -u origin main
   ```
   git না থাকলে রিপোর পাতায় **Add file → Upload files** দিয়ে পুরো ফোল্ডার টেনে ছেড়ে দিন। খেয়াল রাখুন, `.github` ফোল্ডারটিও যেন ওঠে। এটি লুকানো ফোল্ডার।

### ধাপ ২ — GitHub Pages চালু করুন
রিপোর **Settings → Pages → Build and deployment → Source** থেকে **GitHub Actions** বাছুন।

এরপর **Actions** ট্যাবে গেলে দেখবেন "সাইট তৈরি ও প্রকাশ" চলছে। সবুজ টিক এলে আপনার সাইট এই ঠিকানায় চালু:
`https://<ইউজারনেম>.github.io/keyari/`

### ধাপ ৩ — অ্যাডমিন প্যানেলে ঢোকার টোকেন বানান
1. https://github.com/settings/personal-access-tokens/new পাতায় যান।
2. **Token name:** `keyari-admin`। **Expiration:** আপনার সুবিধামতো, যেমন ১ বছর।
3. **Repository access → Only select repositories** থেকে শুধু `keyari` রিপো বাছুন।
4. **Permissions → Repository permissions** অংশে দুটি অনুমতি দিন:
   - **Contents:** Read and write
   - **Actions:** Read and write (প্রকাশের অবস্থা দেখা ও "এখনই সাইট তৈরি" বোতামের জন্য)
5. **Generate token** চাপুন। যে `github_pat_…` কোডটি আসবে, কপি করে রাখুন।
6. `https://<ইউজারনেম>.github.io/keyari/admin/` খুলে টোকেনটি দিয়ে প্রবেশ করুন। মালিক ও রিপোর নাম নিজে থেকেই বসানো থাকবে।

> টোকেনটি শুধু আপনার ব্রাউজারে জমা থাকে, আর কোথাও পাঠানো হয় না। কাউকে টোকেন দেবেন না। প্রত্যেক সম্পাদক নিজের GitHub অ্যাকাউন্ট থেকে নিজের টোকেন বানাবেন।

### ধাপ ৪ — নিজের ডোমেইন (thekeyari.com) যুক্ত করা
⚠️ **ডোমেইন সরানোর আগে অবশ্যই পুরোনো সাইটের ছবিগুলো এখানে নিয়ে আসুন।** এখন কভার ছবিগুলো পুরোনো WordPress সাইট থেকে দেখানো হচ্ছে।
**Actions → "WordPress আমদানি / ছবি স্থানান্তর" → Run workflow** খুলে "ছবি স্থানান্তর" বাছুন। এতে সব ছবি রিপোতে চলে আসবে।

এরপর:
1. অ্যাডমিন → **সেটিংস → ডোমেইন**-এ যান। "কাস্টম ডোমেইন"-এ `thekeyari.com` লিখুন, "সাইটের ঠিকানা"-য় `https://thekeyari.com`।
2. ডোমেইন যেখান থেকে কেনা, সেখানকার DNS সেটিংসে যোগ করুন:
   - চারটি **A** রেকর্ড (`@`): `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - একটি **CNAME** রেকর্ড: `www` → `<ইউজারনেম>.github.io`
3. রিপোর **Settings → Pages → Custom domain**-এ `thekeyari.com` লিখে সেভ করুন। কিছুক্ষণ পর **Enforce HTTPS** টিক দিন।

### এডিটর: লেখালেখির সব টুল

**অনুচ্ছেদ (InDesign-এর Paragraph panel-এর মতো)**
- **সারিবদ্ধতা:** বাম, মাঝ, ডান, সমপ্রান্তিক। সমপ্রান্তিকে শেষ লাইন বামে, মাঝে বা ডানে রাখা যায়, আবার সব লাইনও সমপ্রান্তিক করা যায়। বাঁধাইয়ের দিকে বা বিপরীতে (start/end) সারিবদ্ধ করা যায়।
- **ইন্ডেন্ট:** বাম ও ডান ইন্ডেন্ট, প্রথম লাইনের ইন্ডেন্ট, ঝুলন্ত ইন্ডেন্ট।
- **ফাঁক:** অনুচ্ছেদের আগে ও পরে ফাঁক, লাইনের উচ্চতা।
- **অক্ষর ও শব্দের ফাঁক:** ট্র্যাকিং (অক্ষর-ফাঁক), শব্দ-ফাঁক, হাইফেনেশন।
- **বিশেষ বিন্যাস:** ড্রপ ক্যাপ (২, ৩ বা ৪ লাইন), স্মল ক্যাপস, অরফান ও উইডো, অনুচ্ছেদ না ভাঙা।
- **রুল ও শেডিং:** উপরে, নিচে ও বামে রুল (দাগ), পটভূমির রং, ভেতরের ফাঁক, গোল কোণা।
- **কলাম ও দিক:** ২ থেকে ৪ কলাম, কলামের মাঝে রুল। লেখার দিক বাম→ডান বা ডান→বাম (আরবি/উর্দু উদ্ধৃতির জন্য)।
- **ফরম্যাট পেইন্টার:** এক অনুচ্ছেদের বিন্যাস কপি করে আরেকটিতে বসানো যায়।

- **কি-বোর্ড শর্টকাট:** `Ctrl+S` সংরক্ষণ, `Ctrl+Shift+P` অনুচ্ছেদ বিন্যাস, `Ctrl+Shift+C` অক্ষর বিন্যাস, `Ctrl+Shift+F` টীকা।

## ৩. SEO, অর্থাৎ সার্চে উপরে থাকার জন্য যা করা আছে

- প্রতিটি পাতা আগে থেকেই তৈরি HTML। গুগল সঙ্গে সঙ্গে পুরো লেখা পড়তে পারে।
- `lang="bn"` দেওয়া আছে, আর সব তারিখ ও সংখ্যা বাংলায়।
- প্রতিটি পাতার নিজস্ব শিরোনাম (যেমন "আগুনের জল — সমর ইসলাম | কেয়ারি"), মেটা বর্ণনা ও ক্যানোনিকাল লিংক।
- Open Graph ও Twitter Card আছে, তাই ফেসবুকে শেয়ার করলে বড় কভার ছবি দেখায়।
- Schema.org তথ্য: Article, BreadcrumbList, WebSite (সাইটের ভেতরে সার্চসহ), Organization, ProfilePage, CollectionPage।
- `sitemap.xml` (ছবিসহ), `news-sitemap.xml`, `robots.txt` ও RSS (`/feed.xml`)।
- **পুরোনো WordPress-এর সব URL অপরিবর্তিত।** তাই এখনকার র‍্যাংকিং হারাবে না। পুরোনো `/?s=` সার্চ লিংকও কাজ করে।
- **দ্রুত লোড:** ছবি lazy-load ও WebP, ফন্ট একবারই লোড হয়, কোনো ভারী লাইব্রেরি নেই।

**প্রকাশের পর একবার যা করবেন:**
1. Google Search Console-এ সাইট যোগ করুন। যাচাই কোডটি অ্যাডমিন → সেটিংস → SEO-তে বসান।
2. সেখানে `sitemap.xml` জমা দিন।
3. Bing Webmaster Tools-এও একই কাজ করুন।

## ৪. নিজের কম্পিউটারে চালানো (ঐচ্ছিক)

Python ৩.৯ বা এর পরের সংস্করণ লাগবে। বাড়তি কোনো প্যাকেজ লাগে না।
```bash
python build.py --serve
```
- সাইট দেখা যাবে http://localhost:8000/ ঠিকানায়।
- অ্যাডমিন খুলবে http://localhost:8000/admin/ ঠিকানায়, **লোকাল মোডে**। এই মোডে টোকেন লাগে না, পরিবর্তন সরাসরি `content/` ফোল্ডারে জমা হয়।
- কাজ শেষে `git push` করলে অনলাইনেও প্রকাশ হবে।

```
content/              ← সব লেখা ও সেটিংস (অ্যাডমিন প্যানেল এগুলোই বদলায়)

admin/                ← অ্যাডমিন প্যানেল
build.py              ← সাইট বানানোর প্রোগ্রাম (content → dist/)

```

## ৬. জরুরি কিছু কথা

- **গোপনীয়তা:** Public রিপোতে `content/` ফোল্ডারের সব কিছু, **খসড়াসহ**, যে কেউ GitHub-এ গিয়ে পড়তে পারে। খসড়া গোপন রাখতে চাইলে রিপোটি **Private** করুন। তবে Private রিপোতে GitHub Pages চালাতে GitHub Pro বা Team প্ল্যান লাগে।
- **মন্তব্য:** স্ট্যাটিক সাইটে মন্তব্য জমা রাখতে একটি বাইরের সেবা লাগে। আমাদের প্রস্তাব **Cusdis**: বিনামূল্যে, পাঠককে অ্যাকাউন্ট খুলতে হয় না, আর আপনি অনুমোদন দিলে তবেই মন্তব্য প্রকাশ হয়। অ্যাডমিন → সেটিংস → মন্তব্য-এ App ID দিলেই চালু হবে। ততদিন লেখার নিচে "ইমেইলে বা ফেসবুকে মতামত" বোতাম দেখাবে।
- **নির্ধারিত লেখা:** ভবিষ্যতের তারিখ দিলে লেখাটি সেই সময়ের পরের ঘণ্টায় নিজে থেকে প্রকাশ হবে। তবে রিপোতে ৬০ দিন কোনো কমিট না হলে GitHub এই ঘণ্টাভিত্তিক কাজ বন্ধ করে দেয়। তখন Actions ট্যাব থেকে আবার চালু করতে হয়।
- **একসাথে কয়েকজন সম্পাদক:** প্রত্যেককে রিপোর Settings → Collaborators-এ যোগ করুন। তারপর অ্যাডমিন → ব্যবহারকারী পাতায় তার GitHub নাম ও ভূমিকা দিন।
